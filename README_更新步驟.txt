丙級練習教室 APP V3.4｜更新步驟

這版新增：
- 蛋糕丙級／中餐丙級／麵包丙級
- 每個項目可選上午、下午
- 上午與下午各自獨立計算名額與候補
- 管理員後台可直接修改日期、上午/下午是否開放、名額上限、費用
- 管理員後台可永久刪除報名資料（二次確認）
- 「現場繳費」改成學員頁大字重點
- 舊報名資料保留；沒有時段的舊資料會顯示「未指定」

【更新順序】

一、先備份舊 Apps Script
1. 打開 Google Sheet
2. 擴充功能 → Apps Script
3. 把目前 Code.gs 全選複製
4. 貼到記事本備份

二、更新 Code.gs
1. 在 Apps Script 打開 Code.gs
2. 全選舊程式
3. 貼上這一包裡新的 Code.gs
4. 按「儲存」

三、重新部署
1. Apps Script 右上角「部署」
2. 選「管理部署」
3. 找到目前 Web App → 按鉛筆編輯
4. 版本選「新版本」
5. 執行身分：我
6. 誰可以存取：任何人
7. 按「部署」

若是更新原本部署，/exec 網址通常不會改。

四、更新 GitHub
1. 到 GitHub repository
2. 找到 index.html
3. 先下載舊 index.html 備份
4. 用這一版 index.html 覆蓋
5. Commit changes
6. 等 GitHub Pages 更新 1～3 分鐘
7. 手機重新整理

【第一次啟用】
Apps Script 第一次收到請求後，Google Sheet 會自動新增「場次設定」工作表。

預設：
蛋糕丙級｜10/21（三）
中餐丙級｜11/4（三）
麵包丙級｜日期待公告

三個項目預設：
上午開放：是
下午開放：是
上午上限：6
下午上限：6
費用：1500
啟用：是

原本「報名資料」最右邊會新增一欄「時段」。
舊資料不會刪除；舊資料若沒有時段，後台會顯示「未指定」。

【以後修改練習日期】
1. 打開你的登記網站
2. 點「管理員後台」
3. 輸入管理員密碼
4. 找到「練習場次設定」
5. 直接修改日期，例如：
   蛋糕丙級：10/21（三） → 11/18（三）
6. 按「儲存設定」

學員頁會跟著更新，不用再改 GitHub。

也可以直接：
- 關閉上午
- 關閉下午
- 改上午上限
- 改下午上限
- 暫時隱藏某個練習項目

【取消 vs 刪除】
取消：
- 資料仍留在 Google Sheet
- 適合學員臨時不來
- 若有候補，系統會自動遞補

刪除：
- Google Sheet 該列永久刪除
- 無法復原
- 建議只用於測試資料或錯誤資料
- 刪除前會要求二次確認
